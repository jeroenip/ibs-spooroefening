# Spoorcrisis IBS-oefening

Tabletop-oefening voor crisiscommunicatie in de spoorwereld. Je labelt binnenkomende signalen volgens IBS (informatiebehoefte, schadebeperking, betekenisgeving) en adviseert het crisisteam vanuit een rol.

- Drie fictieve scenario's: ontsporing goederentrein, landelijke storing verkeersleiding, aanrijding op een overweg
- Drie rondes per scenario
- Vijf rollen: communicatieadviseur, woordvoerder, omgevingsanalist, public affairs-adviseur, redacteur
- Solo of met een groep aan tafel

## Spelen

Open `index.html` in een browser. Er is geen installatie of server nodig.

Scenario's, signalen en uitwerkingen staan als data bovenaan het script in `index.html` en zijn daar aan te passen.
